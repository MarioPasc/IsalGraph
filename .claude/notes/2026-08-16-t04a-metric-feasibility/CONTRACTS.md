## 1. Strata and the sample record — track A defines, A and B import

In `datasets.py`:

```python
#: competitors.md 3.1's six node-count strata, frozen.
STRATA: tuple[tuple[int, int], ...] = ((2, 5), (6, 9), (10, 12), (13, 20), (21, 40), (41, 10**9))


@dataclass(frozen=True, slots=True)
class SampleRecord:
    dataset: str    # a member of ALL_DATASETS
    index: int      # index into datasets.load(dataset).graphs
    n_nodes: int
    stratum: int    # 0..5, an index into STRATA
    suite: str      # "suite1" | "suite2", from suite_of(dataset)


def pooled_stratified_sample(
    names: Sequence[str], k: int, *, seed: int
) -> tuple[SampleRecord, ...]: ...
```

**Allocation, frozen.** Pool every graph of `names`, bin by `n_nodes` into `STRATA` (first matching
bound wins). Let `populated` be the strata with at least one member, in ascending order.
`base, rem = divmod(k, len(populated))`; the quota of populated stratum `i` is
`base + (1 if i >= len(populated) - rem else 0)` — **the remainder goes to the largest strata**. One
`random.Random(seed)`, consumed stratum by stratum in ascending order, each stratum's candidate list
ordered by `(names.index(dataset), index)`. A stratum with fewer members than its quota contributes
all of them and the shortfall is **not** redistributed; it is reported.

The return is sorted by `(stratum, names.index(dataset), index)` and is a pure function of
`(tuple(names), k, seed)`.

`stratified_sample` — the per-dataset proportional sampler — is **deleted**. It is not §3.1's
protocol and nothing outside `grid.main` calls it.

## 3. `Cell` — track A defines, track C reads

```python
@dataclass
class Cell:
    backend: str
    metric: str
    applicable: bool = True            # the pairing can exist at all
    reason: str | None = None
    candidate: bool = True             # section 4 -- eligible to be a PRIMARY distance
    f1_defined_frac: float | None = None       # over ENCODABLE pairs only
    f1_n_pairs: int | None = None              # the denominator
    f2_declared_pseudometric: bool | None = None
    f2_violations: dict[str, int] | None = None
    f3_invariant: str | None = None            # "k/attempted"
    f3_skipped: int | None = None              # graphs the backend raised on
    f4_zero_mass: float | None = None
    f4_coeff_variation: float | None = None
    f6_ms_per_pair: float | None = None            # all defined pairs
    f6_ms_per_pair_large: float | None = None      # both graphs n >= 21 (strata 4-5)
    f6_over_advisory_limit: bool | None = None     # f6_ms_per_pair > 1.0; ADVISORY, never a gate
    passes_selection: bool = False
    excluded_because: str | None = None
```

Field names and semantics are frozen. **Do not rename or drop a field**; track C indexes them.

## 4. The candidate rule — track A implements

A metric is a **candidate** for a representation iff `metric.consumes in {"symbols", "frame",
"features"}`. `consumes == "order"` (`size_null`) reads no part of the encoding and is **never
eligible as a primary distance**:

```python
cell.candidate = False
cell.excluded_because = (
    "baseline: consumes 'order'; not a candidate distance (competitors.md 3.2)"
)
```

`Capability.BASELINE` on the **backend** keeps its existing meaning and is also never selectable.
**Both cells are still measured and printed in full** — competitors.md §3.2's "every cell attempted,
a failure is a result" is unchanged.

Selection, otherwise verbatim from competitors.md §3.4: among `candidate` cells with
`f1_defined_frac == 1.0`, no observed F2 violation, F3 invariant on **every attempted** graph,
`f4_zero_mass <= 0.5` and `f4_coeff_variation >= 1e-6` — take `min` on
`(f6_ms_per_pair, metric_name)`. **F6 is the tie-break and never a gate.**

**F5-blindness is structural.** `grid.py` and `datasets.py` must not import
`isalgraph.competitors.ged_reference`, `scipy.stats`, `numpy`-loaded GED, or anything that reaches
one. The existing import-closure test in `tests/unit/test_competitors_core.py` must stay green.

## 5. F5 JSON — track B writes, track C reads

`python -m isalgraph.competitors.f5 --grid <grid.json> --out <path>` writes:

```jsonc
{
  "protocol": "T-04a-F5",
  "note": "DESCRIPTIVE. F5 is not an input to distance selection.",
  "seed": 42, "n_graphs": 200, "bootstrap_resamples": 2000,
  "primary_distance_source": "<absolute path to the grid json>",
  "primary_distance": {"<backend>": "levenshtein"},
  "results": {
    "<key>": {
      "dataset": "iam_letter_low",
      "suite": "suite1",
      "reference": "exact",             // "exact" | "lb" | "ub"
      "n_graphs": 200,
      "n_unencodable": {"<backend>": 0},
      "views": {
        "all_pairs": {
          "size_null": {"rho": 0.899, "p": 0.0, "ci": [0.88, 0.92], "n_pairs": 19900},
          "<backend>": {"metric": "levenshtein", "rho": 0.925, "p": 0.0,
                        "ci": [0.90, 0.94], "n_pairs": 19900,
                        "n_undefined": 0, "zero_frac": 0.01, "reason": null}
        },
        "equal_n": { "...": "same shape" }
      }
    }
  }
}
```

- `<key>` is `"<dataset>"` for Suite 1 and **`"<dataset>::lb"` / `"<dataset>::ub"`** for Suite 2.
  **Two separate records, never interpolated** (approx_ged.md §4).
- A backend with no admissible distance in `primary_distance` is emitted with
  `"rho": null, "reason": "no admissible distance (T-04a selection)"` — it is a printed absence, not
  a missing key.
- `ci` is a graph-level percentile bootstrap (D2): 2,000 resamples **of graphs** with replacement,
  `random.Random(42)`, the **same resample indices reused across every representation within a
  dataset and view** (D7). `null` when fewer than three pairs survive.
- Suite 1 uses certified pairs only (`certified_mask`). Suite 2 uses `lb_matrix` / `ub_matrix` from
  `source/APPROX_GED/{LB,UB}/<ds>.npz`, filtered with `np.isfinite`, **never** `np.isnan`.
- `graph_ids` alignment between cohort and matrix is **asserted**, as `load_ged` already does.

## 7. Environment, verbatim

```bash

$PY -m pytest tests/unit/<your test file> -q     # ONLY your own file, plus the ones your track names
$PY -m ruff check --fix src/ tests/

```

`$PY -c "import isalgraph; print(isalgraph.engine())"` must print `cpp`. **Never** set
`PYTHONPATH=$REPO/src` — it shadows the installed package and silently falls back to pure Python,
which makes every timing fiction.

**Do not run the full suite** (`pytest tests/ -q`) — a peer's half-finished edit will make it fail
and the failure is not yours. The orchestrator runs it at merge.

**No worktrees on this wave.** `isalgraph.core._native` is path-pinned to the main checkout, so a
worktree would run the *installed* code rather than your edits — your tests would pass against
someone else's file and nothing would error. All three tracks therefore work **in place, in the same
checkout, on the one shared branch `ticket/T-04a`**. That is why the file ownership in §0 is
absolute and why these two rules are not negotiable:

- **Stage by explicit path.** `git add src/isalgraph/competitors/grid.py tests/unit/test_competitors_grid.py`
  — never `git add -A`, never `git commit -a`. A peer's half-finished file swept into your commit is
  unrecoverable attribution.
- **Commit incrementally**, every working increment, not once at the end. Sessions die; an
  uncommitted module is a module the orchestrator cannot merge.

If `git status` shows a modified file you do not own, **leave it alone and do not stash** — a peer is
editing it right now.
